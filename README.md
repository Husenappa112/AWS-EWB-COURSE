# SHEK'sLMS

> Enterprise-Grade Multi-Tenant Learning Management System inspired by TalentLMS and modern 2026 AI-driven online training platforms.

---

## 🌟 Overview
SHEK'sLMS is a production-quality Learning Management System built for organizations to create corporate training programs, manage learners and employees, deliver multimedia curriculum, conduct assessments, issue certificates, and track compliance.

### Primary Portals
1. **Super Admin Portal**: Complete multi-organization governance, tenant provisioning, system health, and global audit logs.
2. **Trainer / Instructor Portal**: Visual course authoring, multimedia uploads, learning paths, question banks, and grading.
3. **Learner Portal**: Course catalog, distraction-free player, interactive assessments, certificates, notes, and gamification (points, badges, leaderboards).

---

## 🏗️ Tech Stack
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide React
- **Backend**: Node.js, Express.js, TypeScript, REST API
- **Database & ORM**: PostgreSQL, Prisma ORM
- **Security**: JWT tokens, bcrypt, RBAC, multi-tenant isolation, rate limiting, Helmet
- **Intelligence**: Pluggable AI service for automated course and quiz generation
